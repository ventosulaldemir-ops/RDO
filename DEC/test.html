Metodologia

Civil e Elétrica/MEP usam unidades diferentes (m²/serviço vs pontos), então não dá pra somar os totais direto. A média simples trata as duas frentes como igualmente importantes; a média ponderada pesa pelo número de itens de cada frente. Nenhuma substitui uma curva de avanço físico oficial (ponderada por custo ou HH) — use como estimativa gerencial, não como número contratual.

O histórico é salvo no navegador (localStorage) a cada abertura. A projeção de conclusão usa o ritmo médio dos últimos registros: se o avanço médio diário for X, estima quanto falta para chegar a 100%.
